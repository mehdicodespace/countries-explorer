# Flag assets

The REST Countries API provides the flag images used by most records. These local SVGs fill in records that have no ISO code or hosted flag URL:

- `abkhazia.svg` — [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Flag_of_the_Republic_of_Abkhazia.svg)
- `northern-cyprus.svg` — [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Flag_of_the_Turkish_Republic_of_Northern_Cyprus.svg)
- `somaliland.svg` — [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Flag_of_Somaliland.svg)
- `south-ossetia.svg` — [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Flag_of_South_Ossetia.svg)

Each source file is marked public domain on Wikimedia Commons.
